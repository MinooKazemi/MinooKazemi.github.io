# Phase 1 — homepage prototype

## Scope
Homepage only: navigation, hero, four selected works, short biography, portrait placeholder and contact/footer. About and project pages are intentionally not created. No deployment configuration or Pages activation is included.

## Files
- index.html: semantic page and factual content
- assets/css/styles.css: responsive editorial layout
- assets/js/main.js: progressive navigation enhancement
- preview.html: standalone mirror for review; regenerate after source edits
- assets/images/README.md: image replacement guidance

Open index.html directly in a browser, or serve this directory with any static HTTP server. No install or build step is required. All site assets use relative paths.

## Content
Biography is based only on the supplied brief. No resume was accessible in this session. No employers, education, achievements, outcomes or years of experience have been invented.
The GitHub account is supplied by the user. Email and other social profiles remain clearly labeled pending content; a commit-author email is not treated as an approved public contact address.
Project tiles are noninteractive until the actual case studies exist. Placeholder numbers are layout markers, not representations of design work. Portrait is a typographic placeholder only.
